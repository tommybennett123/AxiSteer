# AxiSteer pitch website

A static site (no build step). Files:

- `index.html`, `style.css`
- `images/`

## Publish on GitHub Pages
1. Create a new repository and upload everything in this folder (keep `index.html` at the top level).
2. Repository **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main` / `(root)`.
3. Your site appears at `https://<username>.github.io/<repo>/` after a minute or so.
